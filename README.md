# LungeHungerLock

LungeHungerLock is a Minecraft plugin designed to prevent players from losing hunger or saturation while using a spear with the lunge attack. This plugin is perfect for servers that want to maintain balanced gameplay by ensuring that players using spears are not penalized with hunger loss during combat.

## Install

1. Download the LungeHungerLock plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Ensure the plugin is installed and enabled on your Minecraft server.
2. Players will automatically benefit from the hunger lock feature when they use a spear with the lunge attack.
3. No additional commands or configurations are required.
